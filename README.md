# 🍳 PDN AI Recipes

🚀 AI-powered cooking assistant that turns your leftovers into delicious recipes.

---

## 🌐 Live Project

👉 https://pdn-ai-recipes.vercel.app

---

## ✨ Features

- AI recipe generation
- Pantry-based suggestions
- User authentication (Clerk)
- Subscription system (Stripe)
- Beautiful UI (Next.js)

---

## 🛠 Tech Stack

- Frontend: Next.js
- Backend: Strapi
- Auth: Clerk
- Payments: Stripe
- AI: Gemini API
